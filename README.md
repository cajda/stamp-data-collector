# Stamp Data Collector

A desktop application for managing a personal stamp collection. Built with Python and Tkinter.

## Features

- Add, edit, and delete stamp records
- Fields: code, country, denomination, condition, perforations, watermark, catalog reference, colors, notes
- Attach watermark and stamp images with thumbnail preview (requires Pillow)
- Save and load collections in XML format
- Export to CSV

## Requirements

- Python 3.x
- Pillow (optional, for image preview): `pip install Pillow`

## Usage

```
python stamp_collector.py
```
